# Practise & Solution.

Key Differences
Purpose:

Binary Search: Efficiently searches for an element in a sorted array.
BST: Provides efficient data insertion, deletion, and search operations, maintaining an order of elements.
Data Requirements:

Binary Search: Requires a sorted array or list.
BST: Does not require the data to be sorted beforehand; it maintains the order dynamically.
Operations:

Binary Search: Only supports searching.
BST: Supports searching, insertion, and deletion, and allows for various traversals (inorder, preorder, postorder).
